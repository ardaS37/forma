## Seçenek A: Bu projeden yayımlamak

1. Projeyi GitHub deposuna gönder.
2. Depoda Settings → Pages → Build and deployment → Source: Deploy from a branch.
3. Branch: `main` (veya kullandığın dal), klasör: `/docs`; Save.
4. Pages ekranındaki canlı HTTPS adresini kullan. Proje deposunda adres genellikle `https://KULLANICI.github.io/DEPO/` olur.

## Seçenek B: Ayrı gizlilik deposu

`docs/index.html` ve `docs/.nojekyll` dosyalarını ayrı deponun köküne koy. Pages ayarında bu kez `/(root)` seç. `KULLANICI.github.io` adlı kullanıcı sitesi deposuna eklersen, adres `https://KULLANICI.github.io/` olur. Mevcut sitende başka bir ana sayfa varsa bu dosyayı `privacy.html` adıyla ekleyebilirsin; adres `/privacy.html` olur.

## Play Console

Canlı sayfanın oturum açmadan açıldığını kontrol et; URL'yi App content → Privacy policy alanına ekle. GitHub kaynak dosyası (`github.com/.../blob/...`) veya düzenleme bağlantısını kullanma. Uygulamada da bu politika metni veya canlı bağlantısı bulunmalı; bu dosyayı hazırlamak Android uygulamasına bağlantı eklemez.
